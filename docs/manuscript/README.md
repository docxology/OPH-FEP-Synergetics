# Observers, Blankets, and Screens

Daniel Ari Friedman and Bernhard Mueller compare finite, executable
correspondences across Observer Patch Holography, the Free Energy Principle
and Fuller’s Synergetics. Start with the [abstract](00_abstract.md),
[method](03_method.md), [correspondence ledger](04_correspondences.md)
and [scope](07_scope.md).

The numbered Markdown sections are the source. Keep the
[configuration](config.yaml), [preamble](preamble.md) and
[bibliography](references.bib) here. The
[ontology concordance](90_ontology_concordance.md) is generated from the
project’s terminology data by `scripts/render_docs.py`. Figures come from the
local mathematical probes and are written to `output/figures/`.

See [verification](../VERIFICATION.md#render-the-manuscript) for the pinned
Template PDF and HTML build and output checks.
